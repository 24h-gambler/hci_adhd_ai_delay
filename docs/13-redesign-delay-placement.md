# 13 · 재설계 — 지연 배치 3조건

기준: `docs/spec/발표대본_7분_v1.pdf` SLIDE 9·10, 부록 A
(*AI 챗봇의 응답 지연, ADHD 성인은 어떻게 해석하고 견디는가*, 김대은)

> **묻는 것이 바뀌었다.** 이전 설계는 "얼마나 기다리게 할 것인가"(즉시/중간/긺)였다.
> 재설계는 **"어느 답을 늦출 것인가"**다. 나오는 것은 "몇 초"가 아니라
> **"깊은 답을 늦춰도 되는가, 안 되는가"**다.

---

## 1. 설계

대화 3개(블록) × 9턴. 한 대화는 **깊은 답 3 · 보통 3 · 얕은 답 3**으로 구성된다.

| 조건 | 배치 | 출처 |
| --- | --- | --- |
| **R1** | 깊음 ← 15초 · 보통 ← 8초 · 얕음 ← 3초 | 이루다·Jiang이 하는 방식 |
| **R2** | 깊음 ← 3초 · 보통 ← 8초 · 얕음 ← 15초 | **반대 조건** — 있어야 원인을 배치라고 말할 수 있다 |
| **R3** | 같은 9개 지연을 깊이와 무관하게 무작위 배치 | 규칙 없음 |

**세 조건의 지연 다중집합이 같다.**

```
{15,15,15, 8,8,8, 3,3,3}      3 × (15 + 8 + 3) = 78초
```

산술이 정확히 맞아떨어진다. `app/config.py`가 기동할 때 이 등식을 검증하고,
어긋나면 서버가 뜨지 않는다.

세 조건을 모두 겪게 하는 이유: 하나만 겪으면 "답답했다"로 끝나고,
셋을 겪어야 **비교하는 말**이 나온다.

---

## 2. 공감 깊이를 어떻게 만들고 재는가

답을 미리 고정하면 참가자 말에 못 맞춰 **대화가 가짜가 된다.**
그래서 실시간으로 생성하되 **턴마다 깊이를 지시**한다.

```
① 실시간 생성 (턴마다 깊이 지시)
      ↓
② 사후 평정 — TES, 패널 5~7인
      ↓
③ 지시한 깊이대로 나왔는지 확인 (일치 80% 이상)
      ↓
④ 참가자 지각은 따로 — PETS-ER
```

**만드는 척도 ≠ 재는 척도.** PETS로 자극도 재면 동어반복이 된다.

프롬프트 구조:

```
prompts/system_common.txt   ┐
prompts/system_safety.txt   ├─ 기반(base) — R1/R2/R3에서 완전히 동일
prompts/system_context.txt  ┘
prompts/depth_deep.txt      ┐
prompts/depth_medium.txt    ├─ 턴마다 하나가 기반 뒤에 덧붙는다
prompts/depth_shallow.txt   ┘
```

로그에 해시 두 개를 남긴다. `base_prompt_sha256`은 세 조건에서 같아야 하고,
`prompt_sha256`은 깊이마다 달라야 한다. `manipulation_check.py`가 검사한다.

## 3. CONTRACT P1은 그대로다

지연은 이제 **깊이의 함수이기도 하다.** 그래도 입력 텍스트와는 독립이다 —
깊이가 `(세션, 대화, 턴)`으로 정해지기 때문이다.

```
depth_sequence(session_id, conversation_index)      ← 조건을 인자로 받지 않는다
delay_sequence(session_id, conversation_index, condition)
draw_delay_ms(...)                                  ← 텍스트를 인자로 받지 않는다
```

`depth_sequence`가 조건을 받지 않는 것이 중요하다. 그래야 R1과 R2의 차이가
**"깊은 답에 무엇이 붙느냐"로만** 남는다. 검사가 `inspect.signature`로 확인한다.

## 4. 이전 설계에서 사라진 것

| 사라진 것 | 이유 |
| --- | --- |
| 맥락 2수준 (일상 / 고민 상담) | 하나로 합쳐졌다 — 일상 대화에서 고민을 꺼내는 자리 |
| 공감 강도 A/B/C 고정안 | 깊이가 **조작 변인**이 되었다. 고정할 것이 아니다 |
| 대화 6개 | **3블록이다.** "6개"라고 하지 않는다 |
| 조건별 시간 추정 문항 | 재설계에 없다. 되살리려면 부담(×3)을 다시 재야 한다 |
| Godspeed I | 재설계 문서에 없다. PETS-ER이 지각 척도다 |

**측정 도구**

| 시점 | 문항 |
| --- | --- |
| 대화 직후 (3회) | 불편감 7점 · 한 단어 · 관여 지수 4문항(1–5) · PETS-ER |
| 세션 종료 (1회) | **규칙 탐지 3택** · QDQ |

규칙 탐지 3택은 명세서의 "끝에 3택으로 직접 묻는다"이다. 참가자가 못 맞히면
2수준으로 내리고, **그래도 안 되면 그것이 결과다** — 지연만으로는 공감이
전달되지 않는다는 뜻.
