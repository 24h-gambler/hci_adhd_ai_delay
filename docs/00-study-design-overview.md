# 00 · 연구 설계 요약 (자료 제작의 전제)

이 문서는 `materials/`의 모든 문서가 공유하는 전제를 한곳에 모은 것이다.
설계가 바뀌면 **여기를 먼저 고치고** 나머지 문서를 맞춘다.

---

## 1. 설계 구조

| 요인 | 수준 | 처리 |
| --- | --- | --- |
| 응답 지연 (within) | 즉시 / 중간 / 긺 | 참가자 내 3수준 |
| 대화 맥락 (within) | A 일상 대화 / B 고민 상담 | 블록으로 분리 |

- 참가자 1명당 대화 6개 = 3(지연) × 2(맥락)
- 대화 1개당 **5턴 고정**, 자동 종료 (4턴으로 줄일지는 `OPEN_QUESTIONS.md` Q13)
- 블록 순서(A→B / B→A)와 블록 내 조건 순서를 참가자 절반씩 상쇄

### 지연 조건 정의

| 조건 | 목표 지연 D (초) | 추출 방식 |
| --- | --- | --- |
| 즉시 | 1.0 ~ 2.0 | 턴마다 균등분포에서 무작위 추출 |
| 중간 | 8.0 ~ 9.0 | 〃 |
| 긺 | 16.0 ~ 20.0 | 〃 |

**D는 사용자가 전송한 직후에 먼저 뽑는다.** LLM 호출 시간과 무관하게
`전송 시각 + D`에 응답을 표시한다. 입력 길이와 지연의 상관이 0이어야
conventional 조작이 성립한다 → `analysis/10-manipulation-check-plan.md`.

## 3. 이 문서 묶음이 통제하려는 것

대화 내용이 통제되지 않으면 **지연 효과와 내용 효과가 섞인다.**
같은 "긺" 조건이라도 AI가 좋은 답을 한 대화와 엉뚱한 답을 한 대화의
평가가 달라지면, 조건 차이가 지연 때문인지 답 품질 때문인지 알 수 없다.

| 통제 대상 | 수단 | 문서 |
| --- | --- | --- |
| ① 참가자가 무엇을 말하는가 | 주제 안내 카드 (범위 고정, 내용 자유) | `03` |
| ② AI가 어떻게 답하는가 | 시스템 프롬프트 + 모델·파라미터 고정 | `04`, `prompts/` |
| ③ 대화가 얼마나 길어지는가 | 턴 수 5턴 고정, 자동 종료 | `03 §4` |

통제가 실제로 됐는지는 사후에 수치로 확인한다 →
`analysis/10-manipulation-check-plan.md`.

## 4. 절대 규칙 (모든 자료에 공통)

1. **디브리핑 전까지 지연 조작을 어떤 자료에서도 암시하지 않는다.**
   안내문·카드·설문·인터뷰 초반 문항에 "속도", "빠름/느림", "기다림",
   "반응 시간"이라는 단어를 쓰지 않는다.
2. **시스템 프롬프트는 지연 조건 3수준에서 완전히 동일하다.**
   맥락 A/B 사이에서만 달라진다. 세션마다 프롬프트 SHA-256을 로그에 남긴다.
3. **안내 자료의 분량·형식은 두 맥락에서 동일하게 맞춘다.**
   카드 길이가 다르면 읽는 시간이 달라지고 그 자체가 교란이 된다.
4. **배제 주제 안전 경로가 발동한 턴에는 지연을 적용하지 않는다.**
   → `materials/04-system-prompts.md §5`
