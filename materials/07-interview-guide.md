# 07 · 인터뷰 가이드 (반구조화, 40~50분)

**시점**: 대화 6개 + 설문 완료 후
**녹음**: 필수 (사전 동의 확인 후 시작)
**준비물**: 참가자 로그 화면(연구자 노트북), 조건별 설문 응답 요약, 필기구

---

## ★ 순서에 대한 설계 수정 제안

원래 흐름은 **⑪ 인터뷰 → ⑫ 디브리핑**이었다.
그런데 인터뷰에서 **로그를 화면에 띄우는 순간 지연 조작이 드러난다.**
타임스탬프와 목표 지연이 로그에 그대로 있기 때문이다.

동시에, 이 연구가 가장 알고 싶어 하는 두 가지는 **공개 없이는 물을 수 없다.**

1. 17초를 어떻게 경험했는가 → 조건을 지목해야 물을 수 있다
2. 말과 행동의 불일치 ("신경 안 썼어요" vs 로그상 본인도 느려짐)
   → 로그를 보여줘야 대조가 된다

**따라서 인터뷰를 두 단계로 나누고 그 사이에 공개를 넣는다.**

```
  1단계 (비공개, 약 20분)   ← 대화 전사만 화면에. 타임스탬프 가림
        ↓
  공개 (약 3분)             ← 08-debriefing-script.md §2를 여기서 읽는다
        ↓
  2단계 (공개 후, 약 25분)  ← 로그 전체 공개. 시간·지연·본인 응답 지연
        ↓
  디브리핑 마무리            ← 08-debriefing-script.md §3 이후
```

1단계에서 나온 **자발적 언급**이 가장 값어치가 크다. 공개 전에 참가자가
스스로 속도를 말했는지 여부가 곧 조작 인지의 지표이므로, 이 순서가
데이터를 더 얻는다.

⚠️ 이 순서 변경은 IRB 서류의 디브리핑 시점 기술과 맞물린다 →
`OPEN_QUESTIONS.md` Q10.

---

## 진행 원칙

1. **유도하지 않는다.** 1단계에서 연구자가 먼저 "느렸죠?"라고 묻는 순간
   그 참가자의 데이터는 못 쓴다.
2. **침묵을 견딘다.** 답이 늦게 나와도 채우지 않는다. 5초는 기다린다.
3. **질문은 한 번에 하나.** 두 개를 붙여 물으면 뒤엣것만 답한다.
   ADHD 경향 참가자에게는 특히 그렇다.
4. **되돌아오기를 허용한다.** 이야기가 새면 끊지 말고, 자연스러운 지점에서
   "아까 ○○ 말씀하시던 것 조금 더 여쭤도 될까요"로 돌아온다.
5. **참가자의 말을 그대로 되받는다.** "답답했다"고 하면 "짜증났다"로
   바꿔 말하지 않는다.
6. **중간 휴식.** 공개 지점(1단계 끝)에서 물을 권하고 2~3분 쉰다.

---

# 1단계 · 공개 전 (약 20분)

> 화면에는 **대화 전사만** 띄운다. 시각·지연 정보는 가린다.

## A. 전체 인상 (5분)

- 오늘 여섯 번 대화하셨는데, 전체적으로 어떠셨어요?
- 여섯 개 중에 특별히 기억에 남는 대화가 있나요? 어떤 점에서요?
- 반대로, 별로였던 대화가 있었나요?

> **탐침**: "어떤 점에서 그랬어요?" / "조금 더 말씀해 주실 수 있을까요?"
> **금지**: "속도 때문인가요?" 같은 원인 제시

## B. 대화별 회상 — 전사 대조 (7분)

전사를 하나씩 띄우고 (조건 순서대로가 아니라 **진행 순서대로**):

- 이 대화 기억나세요? 어떤 이야기를 하셨는지 말씀해 주시겠어요?
- 이 대화 중에 뭔가 걸리는 부분이 있었나요?
- 여기서 상대가 답한 것들, 어떻게 느끼셨어요?

> 6개를 다 하면 시간이 부족하다. **참가자가 A에서 언급한 대화 2~3개**를
> 고르고, 언급하지 않은 대화 1개를 더한다.

## C. 자발적 언급 확인 (5분) ★

여기까지 참가자가 **속도·기다림을 스스로 언급했는지** 반드시 기록한다.
아직 언급이 없다면, 아래 순서로 **점점 좁혀 가며** 묻는다.
**언급이 나온 단계 번호를 기록한다.** 이것이 곧 조작 인지 강도의 지표다.

| 단계 | 질문 | 기록 |
| --- | --- | --- |
| C1 | 대화하시면서 불편하거나 어색했던 점이 있었나요? | 여기서 나오면 자발성 최상 |
| C2 | 여섯 번의 대화가 서로 다르게 느껴진 점이 있었나요? | |
| C3 | 대화의 **흐름**은 어떠셨어요? 매끄러웠나요? | |
| C4 | 상대가 답하는 **방식**에서 차이를 느끼신 게 있나요? | |

- C4까지 가도 언급이 없으면 **더 좁히지 않는다.** 그대로 D로 넘어간다.
  "그럼 답이 나오는 데 걸린 시간은요?"는 공개나 다름없다.
- 자발적 언급이 나온 참가자에게는 그 자리에서:
  - 언제 처음 알아채셨어요?
  - 그때 무슨 생각이 드셨어요?
  - **왜 그랬다고 생각하셨어요?** ← 귀인 질문. 여기가 핵심이다.

## D. 대화 상대에 대한 인상 (3분)

- 오늘 대화한 상대를 누군가에게 설명한다면 뭐라고 하시겠어요?
- 대화하는 동안, 상대가 어떤 상태라고 느껴진 순간이 있었나요?
- (자발적 언급이 있었다면) 아까 ○○라고 하셨는데,
  그때 상대가 뭘 하고 있다고 생각하셨어요?

> D는 Godspeed·PETS 점수의 **해석 근거**가 된다. 점수만으로는
> "왜 사람 같다고 했는지"를 알 수 없다.

# 2단계 · 공개 후 (약 25분)

> 이제 **로그 전체를 화면에 띄운다.**

## E. 조건 재구성 (5분)

타임라인을 조건별로 색을 달리해 보여준다.

- 이게 오늘 여섯 대화의 실제 기다린 시간입니다. 보시니까 어떠세요?
- (설문 ① 응답과 나란히 놓고) 여기서 ○초라고 적으셨는데
  실제로는 ○초였어요. 이 차이를 보시니 어떤 생각이 드세요?

> **과대 추정 참가자와 과소 추정 참가자에게 다른 이야기가 나온다.**
> 어느 쪽이든 "왜 그렇게 느꼈을 것 같으세요?"로 이어간다.

## F. 긴 지연의 경험 (7분) ★

가장 긴 조건의 대화를 띄우고:

- 이 대화에서 답을 기다리는 동안, 무슨 생각을 하셨어요?
- 그 시간 동안 뭘 하고 계셨어요? (시선·자세·딴생각)
- 기다리는 게 **어떤 종류의** 불편함이었어요?
  지루한 쪽이었나요, 불안한 쪽이었나요, 답답한 쪽이었나요?
- 그만두고 싶었던 순간이 있었나요? 있었다면 몇 번째쯤이요?

**귀인 탐침** — 아래 중 참가자가 어느 쪽인지 확인한다.

| 귀인 유형 | 확인 질문 |
| --- | --- |
| 처리/사고 | "상대가 생각하고 있다고 느끼셨어요?" |
| 고장/오류 | "뭔가 잘못됐다고 느끼신 적 있어요?" |
| 네트워크/환경 | "인터넷이나 컴퓨터 문제라고 생각하셨어요?" |
| 태도/무관심 | "상대가 성의 없다고 느끼신 적 있어요?" |

> 순서대로 다 묻지 말고, **참가자가 먼저 말한 쪽을 깊게 판다.**
> 다 묻는 순간 사지선다가 되어 자발성이 사라진다.

## G. 맥락에 따른 차이 (4분)

- 콘텐츠 이야기할 때랑 고민 이야기할 때, 기다리는 게 다르게 느껴졌나요?
- (다르다고 하면) 어느 쪽이 더 견디기 어려웠어요? 왜요?
- 고민 이야기를 하다가 답이 늦게 왔을 때, 어떤 느낌이었어요?

> **가설**: 고민 상담 맥락에서 지연이 "무시당함"이나 "부담스러운 침묵"으로
> 해석될 수 있다. 그 해석이 나오는지 본다. 먼저 제시하지 않는다.

## H. 본인의 응답 지연 대조 (5분) ★★

로그에서 **AI 응답이 뜬 뒤 참가자가 다음 입력을 시작하기까지의 시간**을
조건별 평균으로 보여준다.

- 이건 상대의 답이 나온 뒤에, ○○님이 다음 말을 쓰기 시작하기까지
  걸린 시간이에요. 보시니 어떠세요?
- (조건에 따라 달랐다면) 오래 기다린 대화에서는 ○○님도 더 천천히
  쓰기 시작하셨네요. 이건 어떻게 보세요?
- 아까 "별로 신경 안 썼다"고 하셨는데, 이 숫자는 좀 다르게 보이거든요.
  어떻게 생각하세요?

> **말과 행동이 어긋나는 지점**이 이 연구에서 가장 강한 질적 자료다.
> 물어보지 않고 얻은 행동 지표와, 자기보고를 나란히 놓는다.
>
> ⚠️ **추궁하지 않는다.** "거짓말하셨네요"가 되면 안 된다.
> "이건 어떻게 보세요?"까지만 하고 참가자의 해석을 듣는다.
> 참가자가 "모르겠다"고 하면 그대로 둔다. 모르겠다는 것도 발견이다.

## I. 일상 경험과의 연결 (3분)

- 평소에 AI 챗봇 쓰실 때도 비슷한 경험이 있으세요?
- 평소에 뭔가를 기다리는 상황은 어떠세요? 예를 들면 어떤 상황이요?
- 오늘 같은 상황이 실제 서비스에서 일어난다면 어떻게 하실 것 같아요?

> ADHD 경향 집단에서 **일상적 대기 경험**과 오늘의 경험이 연결되는지
> 본다. "평소에도 이래요"가 나오면 그 맥락을 구체적으로 받아 적는다.

## J. 마무리 (1분)

- 오늘 이야기하면서 제가 안 물어봤는데 하고 싶은 말씀 있으세요?
- 이 연구에 대해 궁금한 점 있으세요?

## 연구자 기록 양식 (녹음과 별도, 즉시 작성)

```
참가자 ID:            일시:            블록 순서: A→B / B→A

[1단계]
  자발적 언급 단계:   자발 / C1 / C2 / C3 / C4 / 없음
  첫 언급 시점(대화 #):
  세션 중 연구자에게 속도를 물었는가:  예(대화 #, 조건) / 아니오
  귀인 유형(공개 전):  처리 / 고장 / 네트워크 / 태도 / 없음

[2단계]
  시간 추정 경향:      과대 / 정확 / 과소  (설문 ① vs 실제)
  긴 지연 정서가:      지루 / 불안 / 답답 / 무관심 / 기타(     )

  자기 응답 지연 대조 반응:  인정 / 부인 / 모르겠다 / 재해석
  중단 의사 보고:      있음(대화 #) / 없음

[관찰]
  세션 중 이석·딴짓:
  긴 조건에서의 자세·시선 변화:
  특이사항:
```
