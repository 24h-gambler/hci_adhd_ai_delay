## 문항별 근거

### ① 시간 처리 성분 + 인터뷰 회상 단서

ADHD의 시간 지각 왜곡이 사실이라면 **같은 8초를 더 길게 추정한다.**
조작 점검이 아니라 **독립적 관찰 대상**이다.

| 문구 | 이유 |
| --- | --- |
| **"AI의 답"** | 무엇의 시간인지 분명히 한다. ~~"상대"~~는 금지어다 — 사회적 존재로 미리 규정해 **M3(사회적 귀인)를 유도**한다 |
| **"대체로"** | ~~"평균"~~은 금지어다. 평균을 내려면 여러 차례를 기억해 계산해야 한다. 인지 부담이 크고 정확도도 낮다 |
| **"모르겠음"** | 없으면 아무 숫자나 적게 되어 자료가 오염된다 |

### ② 견딤 (M5와 대조)

"답답" 대신 **"불편"이라는 중립어**를 쓴다. 정서를 특정하지 않아야
인터뷰에서 참가자 자신의 말이 나온다.

7점을 쓰는 이유는 5점보다 변별이 되고 9점보다 부담이 적기 때문이다.

### ③ Holmberg 비교 + 질적 자료

Holmberg가 "정확히 다섯 단어로 요약"을 시켰고 ADHD 참가자가 음성 조건에서
**기계적 서술어를 더 썼다.** 한 단어로 줄여 부담을 낮추되 직접 비교가
가능하게 했다.

**"어떤 단어든 괜찮습니다"가 중요하다.** 없으면 참가자가 "옳은 단어"를
찾으려 든다.

③은 그 자체로 질적 자료다. "답답" "느림" "차분" "기계" "배려" 같은 단어가
나오면 **인터뷰 회상 단계의 최고의 실마리**가 된다.

> "이 대화는 '차분'이라고 쓰셨네요. 어떤 점에서 그러셨어요?"

## 제시 규칙

1. 6회 모두 **동일한 순서** (① → ② → ③).
2. **한 화면에 모두** 넣는다.
3. 되돌아가기·수정을 허용하지 않는다. 화면 상단에 그 사실을 명시한다.
4. 설문 화면에는 차례 표시를 띄우지 않는다.
5. 제시·제출 시각을 로그에 남긴다.

---

## 로그 (`{session_id}.surveys.jsonl`, `kind: "per_condition"`)

```
participant_id, session_id, kind, conversation_index, shown_ts, submitted_ts
responses: {
  time_estimate_sec        (① · "모르겠음"이면 null)
  time_estimate_unknown    (bool)
  discomfort               (② · 1–7)
  one_word                 (③ · 자유 기입)
  block, condition, context
}
```

## ⚠️ 남아 있는 긴장 — 명세서 내부

문항 ①은 응답 시간을 **여섯 번** 묻는다. 그런데 명세서 §5-2 개방 단계의
임무는 "참가자가 응답 시간을 **스스로** 꺼내는지, 몇 번째 발화에서 꺼내는지"
확인하는 것이고, §7은 그것을 `탐지 여부: 자발적 언급 / 유도 후 언급 /
끝까지 언급 없음`으로 기록한다.

첫 대화 직후부터 초 단위를 묻고 나면 그 지표는 사실상 전원 "자발적 언급"이
된다. → `OPEN_QUESTIONS.md` Q19.
