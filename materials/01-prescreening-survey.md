# 01 · 사전 스크리닝 설문 (온라인, 방문 전)

**형식**: 구글 폼 / 소요 5분 이내
**목적**: 참가 자격 판정 + 참가자 특성 기술
**주의**: 이 설문에는 **연구의 진짜 목적(응답 지연 조작)을 암시하는 문항이
하나도 없어야 한다.** 챗봇 사용 빈도 문항도 "속도"나 "기다림"을 묻지 않는다.

## 섹션 2 · K-ASRS (성인 ADHD 자기보고 척도)

> ⚠️ **최종본에서는 검증된 한국어판(K-ASRS) 문항을 그대로 사용한다.**
> 아래는 문항 내용과 채점 규칙을 정리한 것이며, 임의 번역본을 쓰면 안 된다.
> ASRS v1.1은 WHO/Harvard가 공개한 도구이지만 한국어판은 별도 검증본을
> 사용해야 하고, 사용 조건(출처 표기·비상업적 사용)을 IRB 서류에 명시한다.

**구성**: Part A 6문항(스크리너) + Part B 12문항
**응답 척도**: 전혀 없음(0) / 거의 없음(1) / 때때로(2) / 자주(3) / 매우 자주(4)

**Part A 6문항이 다루는 내용** (검증본 문구로 교체할 것)

| # | 내용 영역 |
| --- | --- |
| A1 | 과제의 어려운 부분을 끝낸 뒤 마무리를 짓지 못함 |
| A2 | 체계가 필요한 일을 순서대로 정리하기 어려움 |
| A3 | 약속·해야 할 일을 기억하기 어려움 |
| A4 | 많은 생각을 요구하는 일을 미루거나 시작하지 못함 |
| A5 | 오래 앉아 있을 때 손발을 꼼지락거림 |
| A6 | 지나치게 활동적이거나 무언가를 하지 않고는 못 견딤 |

**채점**: A1~A4는 2점 이상, A5~A6은 3점 이상일 때 "해당"으로 센다.
6문항 중 **4개 이상 해당 → 스크리너 양성.**

### 집단 배정 기준 (⚠️ `OPEN_QUESTIONS.md` Q1에서 확정 필요)

현재 안:

| 집단 | 기준 |
| --- | --- |
| ADHD 경향 집단 | Part A 스크리너 양성 (4개 이상) |
| 비교 집단 | Part A 해당 항목 1개 이하 |
| 제외 | 그 사이 (2~3개) — 경계 구간을 비워 집단 대비를 선명하게 |

- 진단 여부를 별도로 묻되(문항 2-1), **진단 유무를 배정 기준으로 쓰지 않는다.**
  미진단 성인이 다수인 국내 상황에서 진단 기준을 쓰면 표본이 편향된다.

**문항 2-1** · ADHD로 진단받으신 적이 있습니까?
→ 있음(진단 시기: ____) / 없음 / 응답하지 않음

**문항 2-2** · 현재 ADHD 관련 약물을 복용 중이십니까?
→ 예 (복용 시 실험 당일 평소와 같이 복용해 주세요) / 아니오 / 응답하지 않음

## 섹션 3 · 챗봇 사용 경험

| # | 문항 | 보기 |
| --- | --- | --- |
| 5 | AI 챗봇(ChatGPT, Claude, Gemini 등)을 사용해 보신 적이 있습니까? | 있음 / 없음 |
| 6 | 최근 한 달 동안 AI 챗봇을 얼마나 자주 사용하셨습니까? | 사용 안 함 / 한 달에 1~2회 / 주 1~2회 / 주 3~5회 / 거의 매일 |
| 7 | 주로 어떤 용도로 사용하십니까? *(복수 선택)* | 정보 검색 / 글쓰기·번역 / 코딩 / 공부 / 일상 대화 / 고민 상담 / 기타 |
| 8 | AI와 개인적인 고민을 이야기해 본 적이 있습니까? | 있음 / 없음 |

**참가 자격**: 문항 5 = "있음" **AND** 문항 6 ≥ "한 달에 1~2회"
→ 챗봇 인터페이스 자체가 낯설어 생기는 반응을 배제하기 위함.

## 운영 메모

- 스크리닝 결과는 **참가자 ID로만** 실험 데이터와 연결한다.
  (`P01`, `P02` … 매핑표는 암호화하여 연구책임자만 접근)
- ADHD 경향 집단과 비교 집단의 **연령·성별·챗봇 사용 빈도를 대략 맞춘다.**
  챗봇 사용 빈도가 집단 간에 다르면 그것이 교란이 된다.
- 스크리닝 합격자에게 보내는 일정 안내 메일에도 **지연을 암시하는 표현을
  넣지 않는다.** ("AI와 대화를 나누는 연구"까지만 쓴다.)
